Adopted · EStack + detail
A 320 px stack of ideas on the left, the selected idea beside it at about 860 px: the widest side-by-side layout, so the list stays in view while the discussion gets room. Below 1200 px the idea takes the page and a chip leads back to all ideas. Applied to the live Community prototype.
One discussion. An idea has a single Discussion panel, shared with What's new: questions, use cases and workarounds are threads with replies, so there is no second thread to keep in sync.
Deep links. An idea URL opens the list with that idea selected (the idea page below 1200 px), so notifications, release notes and the assistant can still point at one idea.
Rules kept in every layout Row: vote box 56 px, status tile, area tag, author · date, title, one line of text, message count and Follow. Detail: the same header, text, vote and Follow, the progress stepper (wraps when narrow), the team note, then the Discussion expansion panel shared with What's new (summary bar as header; open: threads by three with Show more, opening message and replies with role chips, Reply, new-message field). Question measure 72 characters at most; cards radius 12; a selected row shows the 2 px primary inset. Side sheet (D): `surface-container-low`, 640 px, 16 px left corners, scrim 32 %.
