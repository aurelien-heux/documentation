Can I re-run only the failed checks of a sweep?

Asked 23 NovActive todayViewed 214 times Solved Waiting on an idea · Planned
{{q.score}}

On a big pull request one of the twelve checks fails, often the flaky e2e-reservation suite. Sweep then asks me to re-run the whole sweep, which takes about 12 minutes and re-runs checks that already passed.

Is there a way to restart only the failed check, from the PR page or from the run?

sweep run #4821 · environments-backend · PR 918
✓ build            2m 10s
✓ unit-tests       3m 02s
✕ e2e-reservation  4m 41s   timeout on reserve_env_test
✓ sonar            1m 15s

Not from the PR page today. You can do it from the command line: the runner keeps the passed checks of the last run for 24 hours, so this only runs the failed one.

sweep rerun 4821 --only-failed

A button on the PR page is the idea Re-run only the failed checks, planned for 4.8. Vote for it and you will be told when it ships.

Drafted by the assistant from Docs · checked by Marta Kowalski

The flaky suite can also be retried automatically. Add a retry rule to the check in .sweep.yml; a check that passes on retry is marked flaky instead of failed.

checks:
  e2e-reservation:
    retry: 1          # one automatic retry
    mark-flaky: true

Source: Docs › Sweep › Checks › Retries
