Not from the PR page today. From the command line the runner keeps the passed checks of the last run for 24 hours:

sweep rerun 4821 --only-failed

The button is the idea Re-run only the failed checks, planned for 4.8.

Drafted by the assistant · checked by Marta Kowalski

Add a retry rule to the check in .sweep.yml; a check that passes on retry is marked flaky instead of failed.

checks:
  e2e-reservation:
    retry: 1
    mark-flaky: true
