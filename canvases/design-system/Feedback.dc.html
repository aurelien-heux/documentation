AIToolbox · feedback · proposal Feedback, configurable per feature Each feature decides what it asks, when and to whom; the platform provides the entry points, the form renderer, the context and the routing. Built only from design-system components: tonal button, side sheet, scale (segmented), filter chips, text field, switch, snackbar, feature marks.
One profile per featureSweep, Docs, Chatbot… each owns a feedback profile: on / off, questions, triggers, audience, routing, owner team.
Six question typesThumbs, scale 1–5, NPS 0–10, single choice, multiple choice, text. Max 3 questions per form; one required at most.
Context, not effortThe run, page, environment and app version are attached automatically (user can turn it off); screenshot on request; anonymous option.
Respectful by defaultSampling and a per-user cap (14 days); never during a running action; prompts are dismissible and never modal.

Rotate a secretPlatform guide · updated 3 days ago
Secrets are rotated per environment. The command below rotates a database password on staging-eu, updates the vault entry and restarts every service that mounts it, in dependency order.
aitb secrets rotate --env staging-eu --name db-password
✓ rotated · 3 services restarted · 41 s
What happens nextServices that fail their health check after the restart are rolled back to the previous secret; you get a notification and the run appears in Logs.

Integration in a feature Angular: one <aitb-feedback feature="sweep"> component reads the profile and renders the side sheet; feedback.prompt('sweep.run.finished', { runId }) fires the after-action trigger (the service applies sampling and the per-user cap). Components used: Button (tonal, filled, text), SideSheet (400 px, standard), SegmentedButton for the scale, Chip (filter), TextField (outlined, multiline), Switch, Checkbox, Snackbar, the feature marks in the sheet header, StatusChip in the admin list. Data: each answer stores feature, question ids, values, context (run, page, env, version), user or anonymous, timestamp. Results per feature live in Settings › Feedback › Results (not drawn here). Accessibility: the side sheet traps focus and closes on Esc; the scale is a radio group (arrow keys); prompts are polite live regions, never modal.
