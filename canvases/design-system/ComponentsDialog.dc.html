Dialog with a form

MD3 basic dialog carrying a short form: 560 px max, 16 px corners, surface-container-high, 24 px padding, headline-small title, actions right-aligned. The confirm action is a filled primary button (creating is a decision, not a run); the lime Run button stays out of dialogs.

Anatomy & rules Container 280–560 px wide, 16 px radius, surface-container-high, elevation 3, 24 px padding, scrim scrim at 32 %. Title headline-small (24/32); one line of supporting text in body-medium on on-surface-variant. Fields outlined, 56 px, 16 px gap between rows; the label floats on the dialog colour. Focused = 2 px primary; error = 2 px error + icon + helper text. Mono face for keys, URLs and paths. Choices short enumerations are filter chips (secondary-container when selected); toggles for defaults, checkboxes for options. Actions right-aligned: text button to dismiss, one filled primary to confirm. Never the Run button here, and never a destructive filled button; a delete confirm uses a text button in error. Behaviour focus goes to the first field; Esc = Cancel; a form that needs more than ~6 fields becomes a full-screen dialog or a page.
