AIToolbox · feature marks · final Sweep, Docs, Environments, Chatbot, Notifications Free-standing marks in the design-system colours only: deep violet (primary), teal (ai) and green (tertiary); lighter tones and the neon green on dark. 64 grid, rounded joins, legible at 16 px. The Chatbot mark is the validated brace box, now part of the same family with its own motions. Once (-once files): an entrance that builds the mark, plays one time and holds it, when the feature opens or an action completes (Sweep run finished, docs page loaded, promotion done, assistant opened, notification centre opened); always ends on the static mark. Loop (-loop files): a different, working motion on the mark already in place, repeating while work is in progress (pipeline running, search indexing, deployment ongoing, assistant responding, new notification); starts and ends on the static mark, so it can stop at the end of any cycle. Both use transform, opacity and stroke-dashoffset only, the MD emphasized easing, and stop under prefers-reduced-motion (the static mark shows).
