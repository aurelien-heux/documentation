Release notes

Skill · Camille Martin · v1.3.0

Collects the pull requests merged since the last tag, groups them by Work item type and drafts the release notes in your team's template. When you ask, it adds them to CHANGELOG.md in a pull request and creates the Jira release ticket.

Asks before it does anything that changes something: open pull request, create Jira ticket.

Try asking

“Draft the release notes for environments-backend since 2.14.0”
“What changed in reservation-api this sprint?”
“Add the 2.15.0 notes to CHANGELOG.md and open the pull request”
