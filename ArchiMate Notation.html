ArchiMate notation

Every ArchiMate 3.2 element and relationship type available in Archi, drawn with AIToolbox tokens. Use it to rebuild architecture visuals by type: the layer sets the colour, the aspect sets the shape, the glyph names the type. The same definitions drive the CSS classes, the 24 px icons and the LikeC4 element kinds.

Components

Built on the notation and on the AIToolbox components. Notation components draw the architecture; review components prepare the ARB submission and the ASD. Each one lists its anatomy, sizes, states, rules, accessibility and Angular mapping.

Elements

Box = the figure in diagrams (176 × 72, layer fill, 1 px layer ink, glyph top-right). Tile = the 20 px type mark in lists and tables. Active structure is square, behaviour is rounded, passive structure has a header line, motivation has cut corners.

Relationships

Line style and end markers follow ArchiMate. The LikeC4 column is the relationship kind declared in archimate.c4; LikeC4 draws the same markers.

Plateaus and gap overlay

Every building block is tagged with the plateaus it belongs to (#baseline, #transition-1, #target). Gap views compare two plateaus with a change chip: glyph and word, on the AIToolbox state containers. The layer colour never carries the change.

Usage

✓Do

  • Pick the element type first; colour, shape and glyph follow from it.
  • Show the type tile before an element name wherever several types are listed together.
  • Use Grouping for model folders (ABB, SBB, an Application) and for views that frame a scope.
  • Keep one relationship type per line; use a junction to split or merge paths.

✕Don’t

  • Use a layer colour for a status, a selection or an action. Status stays a glyph + word chip.
  • Recolour a glyph, or draw a glyph without its box or tile.
  • Mix a UML diagram into a building-block view: detailed design lives in the DD files.
  • Invent a type: extend with a specialization of an existing type and a tag.

In code

  • HTML: <span class="ax-tile ax-l-application">svg</span>, box: .ax-box.ax-shape-rect.ax-l-application.
  • LikeC4: deployment-api = application-interface 'Deployment API'.
  • Agents: notation.json lists every type with its layer, aspect, shape and glyph.
  • Angular: the same CSS classes; the icons as an SVG sprite or inline.
