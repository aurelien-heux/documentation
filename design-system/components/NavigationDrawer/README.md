# NavigationDrawer
Opened on demand from the NavigationRail menu button: the rail is the default navigation from 600 px, and every session starts on it. 360 px (300 px shown) drawer on `nav-container` (violet band #EDE4FF in light — darker than the pale containers — night tone 10 in dark), 12 px inset, items 56 px at radius-lg (16 px); hover and active share that shape.
- **Destinations:** Sweep · Environments · Docs · Community (tabs What's new · Guides · Ideas, Manage for admins), each with its feature mark at 24 px (the static `light/` or `dark/` file for the surface), under a "Workspace" section header in label-medium `on-surface-variant`. Trailing counts in label-medium ("3", "3 new"). No Dashboard for now; Settings is in the account menu of the header; the assistant and notifications stay in the header.
- The menu button (close back to the rail) is the first row of the drawer, aligned with the item icons; a 2 px gap of the page `surface` separates the drawer from the top app bar; no border on the content side.
- Active item: `secondary-container` (the pale purple #DED7EB in light) with `on-secondary-container`; others `on-surface-variant`.
- **Bottom:** a **Cookie policy** item (cookie icon, trailing open-in-new icon, opens the policy in a new tab). Nothing under it: no Terms and no version in the navigation. The cookie policy stays one click away on every page, never in the top app bar.
- **Responsive:** Closed by default at every width. From 1200 px the rail menu button opens it as a standard drawer (`mode="side"`, 300 px, pushes the page) until the user closes it; it folds back to the rail while the docked assistant needs the room (page keeps ≥ 720 px). Under 1200 px it only opens over the page (`mode="over"`, scrim): from the rail menu button (600–1199 px) or the top-bar menu (under 600 px).
- **Keyboard and screen reader:** the opener has `aria-expanded` and `aria-controls`; Esc closes an over drawer and focus returns to the menu button. The active item has `aria-current="page"`, the `secondary-container` pill and a 3 px `primary` leading bar (`dt-nav-active`), because the pill alone is 1.1:1 on the band.
- **Angular Material:** `mat-sidenav-container` + `mat-sidenav` with `[opened]="layout.drawerOpen()"` (false by default) and `[mode]="layout.drawerMode()"` (`side` from 1200 px, `over` below), holding a `mat-nav-list`; the rail menu button calls `layout.toggleDrawer()` (`AitWindowClass`, `angular/breakpoints.ts`). Add `class="dt-nav"` on the `mat-sidenav`: both theme files set its `container-background-color` to `nav-container` (side sheets, also `mat-sidenav`, stay neutral). Shape `0 16px 16px 0` via `mat.sidenav-overrides`. Full map and theme files: `angular-material.md`.
