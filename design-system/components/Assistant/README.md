# Assistant

The assistant: a custom inline block beside the page and the conversation inside it. Patterns users already know from ChatGPT, Claude, Gemini and Copilot, in the AIToolbox roles. Spec boards: `mockups/23-assistant-panel`, `mockups/24-assistant-conversation`; prototype: `mockups/prototypes/assistant-panel.html`.

- **Pane** — a custom inline block beside the page under the header (a split view, not a drawer or side sheet: no backdrop, no overlay, no focus trap), on `surface-container-low` in both themes (#FAF4FF / #1D1A27), 400 px by default, resizable 320 – min(640 px, 50 %), width remembered per user. Divider = resize handle: 1 px `outline-variant` line with an always-visible 6 × 40 grip in `outline` (70 %), 12 px hit zone, `col-resize` cursor; hover 100 ms / focus → 2 px `primary` line and a 6 × 48 `primary` grip; drag shows the width; past 240 px it closes; double-click resets to 400; `role="separator"` with arrows ±16 (Shift 64), Home / End. The page keeps ≥ 720 px: the drawer folds to the rail while the block needs the room; under 1200 px the block takes the page area in place beside the rail (the header button gives the page back); on phones it is the NavigationBar Assistant destination. Header: Chatbot mark (once motion on open), conversation title, page context, History, New conversation, Settings, Close. Triggers: the header assistant button toggles it (selected = `secondary-container` pill, `aria-expanded`, tooltip Open / Close assistant ⌘J; typing dots while an answer is written with the block closed, `tertiary` dot when one waits); the Ask chip sends the search-field text (empty: opens and focuses the composer; disabled with its reason while not live); ⌘J toggles, Esc closes and returns focus. Motion: open = width 0 → W, 300 ms `cubic-bezier(.05,.7,.1,1)`, content fades in (200 ms from 80 ms) and slides 16 px; close = 200 ms `cubic-bezier(.3,0,.8,.15)`, content fades first; no transition while dragging; reduced motion → 150 ms fade.
- **Messages** — questions right in `primary-container` bubbles (radius 16, 4 on the tail corner); answers left with the Chatbot mark (24 px, typing loop while writing), no bubble, body-medium `on-surface`, data and code in Open Sans 600, code blocks on `surface-container-highest` with their own Copy. Streamed with a `primary` caret; the list follows the end unless the user scrolled up.
- **Actions on a question** — Edit, Copy, and ‹ n / m › when edited: 28 px icon buttons in `on-surface-variant`, shown on hover / focus. Edit turns the bubble into a field (Enter sends a new version, Esc cancels; ↑ in an empty composer edits the last question); what followed stays with the old version.
- **Actions on an answer** — Copy, Retry, Good, Bad, ‹ n / m ›: always visible under the last answer, on hover for older ones. Retry adds a version. Bad opens the reason form (Wrong or inaccurate · Not helpful · Used the wrong tool · Unsafe · Other + details), sent to the Feedback feature with the conversation attached. While writing, Send becomes **Stop** (`on-surface` fill, square icon); a stopped answer keeps its text and shows “Stopped · Retry”.
- **Tool trace** — a collapsible “Used n tools” box (1 px `outline-variant`, radius 12) above the answer, open while tools run: source tile (AIToolbox tool, skill, or the MCP server’s initials), label, status (spinner, `success` check, `warning`). A missing tool or server says why and links to its setting; the answer never guesses missing data.
- **Approval** — every tool that changes something asks first unless the user chose Always allow: a card on `surface-container` with a 1 px `outline`, lock icon + the question as title (“Run pipeline lint-api?”), arguments in Open Sans 600 on `surface-container-highest`, the reason, a filled action and a text “Don’t run”. Declining is recorded in the trace.
- **Composer** — `field` colour, radius 16, focus = 2 px `primary`; context chip (“Runs page”, `secondary-container`, removable), auto-growing text (Enter send, Shift+Enter new line), Tools button with the count of what is on, Send / Stop. Under it, always: **“The assistant can make mistakes. Check important information before you act on it.”** — body-small 11/15, `on-surface-variant`, centred, not dismissible.
- **Tools, skills, MCP servers** — quick switches in the composer’s Tools menu (this conversation); defaults in Assistant settings (modal dialog, tabs Tools · Skills · MCP servers · History and data). These tabs are views of the Catalog (a rail destination) with a Browse catalog button; a skill added from the Catalog shows here at once. Tools: Always allow / Ask first / Off, “Reads only” or “Changes things” (write tools default to Ask first). Skills: Built-in (one per feature), Organisation, Yours. MCP servers: status pill (Connected `success-container`, Needs sign-in `warning-container`, Can’t reach `error-container`), URL and auth (OAuth or API key), tool list with write tools in `warning-container`, organisation lock (can turn off, not remove), add by https URL with validation. The admin sets the ceiling; users can only be stricter.
- **History** — the header’s History button slides the list over the chat from the left (300 ms in, 250 ms out). Search (titles and questions), Pinned · Today · Yesterday · Previous 7 days · Previous 30 days, current one in `secondary-container`; per item Rename (inline), Pin, Delete (snackbar with Undo, 6 s). Titles come from the first question. Private to the author; kept 90 days by default (30 / 90 / 365, pinned kept); Delete all asks twice.
- **Keyboard and a11y** — Enter / Shift+Enter / ↑ / Esc (menu, then history, then panel) / ⌘J; message list `aria-live="polite"`; labelled icon buttons; approval card is a labelled group; switches `role="switch"`; settings dialog modal, focus returned to its opener.
- **Responsive:** Docked split view from 1200 px, beside the rail (an open drawer folds back to the rail while the page needs the room: page ≥ 720 px). 600–1199 px: the block takes the page area in place beside the rail and the header button gives the page back. Under 600 px: the full-screen NavigationBar destination.
- **Keyboard and screen reader:** ⌘J toggles and Esc closes the top layer only (popover → history → pane), focus returns to the opener; streaming answers are `aria-busy`, then one "Answer ready" from a live region outside the pane; the header button name carries its state ("Assistant, answer ready"); composer and history search outlines are `outline` (4.3:1) and turn 2 px `primary` on focus; the resize grip is `outline` at 100 % at rest; the disclaimer is 12 / 16.
- **Angular Material:** messages in a `cdk-virtual-scroll-viewport` past 100 turns; history and item menus `mat-menu`; settings `mat-dialog` + `mat-tab-group`; permissions `mat-select`; switches `mat-slide-toggle`; snackbar `MatSnackBar` with an Undo action; the block itself is a custom `ait-assistant-pane` with an `aitSplitResize` directive, not `MatSidenav` / `MatDrawer`. Full map and theme files: `angular-material.md`.
